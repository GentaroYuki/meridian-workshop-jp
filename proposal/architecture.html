00要旨

本システムは、Vue 3 のシングルページアプリケーションと FastAPI の API サーバーで構成され、データベースを持たずに JSON ファイルをメモリへ読み込んで動作します。構成自体は単純で、共通のフィルター状態・API クライアント・i18n の基盤も整っています。課題は設計の誤りではなく、前任ベンダーが途中で止めた作業が複数の箇所に残っている点にあります。

06データフロー（フィルター）

画面上部のフィルター（期間・倉庫・カテゴリー・ステータス）の値は、全画面で 1 つの状態を共有しています。

FilterBar.vue（選択）
  └→ useFilters.js（モジュール内の ref = 全画面で共有）
       └→ 各ビューが watch で変更を検知 → getCurrentFilters()
            └→ api.js がクエリパラメータを組み立てる（'all' は送らない）
                 └→ FastAPI: apply_filters() / filter_by_month() でメモリ上を絞り込む
                      └→ Pydantic で検証して返却 → ビューの ref に格納 → computed で集計・表示

サーバー側の共通関数（server/main.py）

  • apply_filters(): 'all' または未指定は無視します。category と status は大文字小文字を区別せずに比較しますが、warehouse だけは完全一致です。現行データでは実害はありません。
  • filter_by_month(): order_date の部分一致で判定します。四半期指定（Q1-2025 形式）は QUARTER_MAP で月に展開しますが、2025 年分しか定義されていません。画面の期間の選択肢（FilterBar.vue）も 2025 年の 12 か月で固定されています。

10セキュリティ上の注意

社内ネットワークでの利用を前提とした作りです。外部に公開する場合は、以下をすべて見直す必要があります。

  • 認証がありません。 API にはだれでもアクセスでき、発注の登録（POST）も認証なしで実行できます。画面の「ユーザー」はモックです。
  • CORS が全許可です。 allow_origins=["*"] と allow_credentials=True の組み合わせです。
  • 開発サーバーが外部から接続できる設定です。 vite.config.js の host: true と allowedHosts: true により、同じネットワーク上の他の端末からアクセスできます。
  • API サーバーは 0.0.0.0:8001 で待ち受けます。
この点は未確認です社内ホスティングの実際のネットワーク構成（ファイアウォール、リバースプロキシの有無）は当社では把握していません。上記の設定が本番環境でも有効になっているかどうかは、貴社 IT 部門にご確認ください。
